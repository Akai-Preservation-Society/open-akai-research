# File formats shared by several machines

Disk and file formats that more than one machine reads or writes belong
here, one Markdown file per format, written as findings (same front
matter and evidence tags; see [../docs/data-formats.md](../docs/data-formats.md)).
A format used by a single machine stays in that machine's `findings/`.

Nothing has been published here yet. The first candidates are listed as
open questions under each machine, for example
[../machines/mpc3000/questions/disk-file-formats.md](../machines/mpc3000/questions/disk-file-formats.md).

This folder is not yet read by `tools/oar.py`. When the first format is
added, extend the tool so that formats are validated and indexed too.
